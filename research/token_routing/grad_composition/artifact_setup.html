Setup

Model. Qwen3.5-4B (32 blocks: Gated DeltaNet linear attention, full attention at blocks 3, 7, …, 31), olmo-core, bf16, parameters frozen; one teacher-forced forward + backward of the answer cross-entropy (no-cot) per row on one H100 (Beaker; a first pass on Lambda A100).

Rows. mt4 rows: mt4s1952 rows 1464–1527 of contradiction, nq, outlier, oolong. The mt4 shards are true prefixes, so no mt4 run up to s1464 trained on them; eval_size = 64 rows per task. mt11 rows: mt11s960 rows 832–959 of all 11 tasks. The mt11 shards are shuffled supersets, so only rows that no mt11 training shard contains are used: eval_size = 32–42 per task, identical for every checkpoint.

Checkpoints (weka ctc_suite/ckpts, Beaker H100). Repaired base q35-4b-base-markerfix. mt4 dense at LR 5e-6 after 31 / 61 / 122 / 366 steps (f8k-mt4-dense-s488st31/st61/s488/s1464-tdc-lr5e-06), and at LR 2e-6 after 366. mt11 dense at LR 2e-6 after 165 / 330 / 495 steps (f8k-mt11-dense-s240/480/720-tdc). Online routers otr10M8 (keep 10%, drop before block 8): mt4 after 366 steps, mt11 after 330 and 495. A first Lambda pass reproduced base exactly; its separately trained dense-366 run differs from the Beaker one by ≤0.03 in shares and 0.08 in ablation ΔCE.

Per token t, block b. G = ‖dL/dhb,t‖ at each block input; residual updates of the mixer and the FFN; first-order skip attribution ⟨dL/dh, Δh⟩; the token's share of the parameter gradient at each output projection (‖δt‖·‖xt‖, the exact norm of its rank-1 term); attention mass from the answer-predicting positions at the 8 full-attention blocks. Plus exact per-block parameter-gradient norms.

Limits

All rankings are full-context oracles: a router scores tokens from early hidden states and, in a pyramid, on an already-dropped context. The split-fidelity curve counts gradient energy, not direction; dropping also changes the kept tokens' gradients (the grad-sim work found that is the larger effect). The ablation is forward-only (ΔCE at a fixed checkpoint), not a training run. 64 (mt4) or 32–42 (mt11) rows per task is well below the 500-example default; differences under about ±0.03 in shares are noise. Gold flags come from gold_fingerprints.json; oolong and reorder have none.
